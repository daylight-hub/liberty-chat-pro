RNode Config Tool

Start | Software | RNode Config Tool | Guides


Liberty Chat Pro includes the LCS RNode Configuration Tool, for flashing and provisioning RNode firmware on compatible boards.

Please note! The tool uses WebSerial, so it requires Chrome or Edge on desktop. Firefox and iOS Safari cannot access serial devices.

To flash a board you will need firmware packages. You can obtain these in different ways:
  • Liberty Chat Pro can download the latest release automatically and place it in this repository.
    • Open the Repository menu item and select Update Contents.
    • They will then appear on the Software page.
  • Download them manually from the latest RNode Firmware release.
  • Compile them from the RNode Firmware source package included in this repository.
